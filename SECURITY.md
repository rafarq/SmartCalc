# Security Policy

## Reporte de Vulnerabilidades

Si descubres una vulnerabilidad de seguridad en SmartCalc, no la publiques en un issue público.

Envía el reporte de forma privada a los mantenedores del proyecto, preferiblemente mediante una **GitHub Security Advisory** o el canal privado que use el propietario del repositorio.

Incluye, si es posible:

- Descripción del problema
- Pasos para reproducirlo
- Impacto esperado
- Versiones afectadas
- Posible mitigación o propuesta de corrección

## Qué Esperar

Los mantenedores intentarán:

- Confirmar la recepción del reporte
- Evaluar el impacto
- Preparar una corrección
- Coordinar la divulgación responsable cuando proceda

Si no estás seguro de que el problema sea realmente de seguridad, repórtalo igualmente por canal privado.
