# Code of Conduct

## Nuestro Compromiso

Para fomentar una comunidad abierta y profesional, quienes participen en este proyecto se comprometen a mantener un entorno respetuoso, constructivo y libre de acoso.

## Comportamiento Esperado

- Usar un tono respetuoso y profesional
- Aceptar feedback técnico de buena fe
- Centrarse en el problema y no en la persona
- Compartir contexto suficiente para colaborar con eficacia
- Respetar diferentes niveles de experiencia y puntos de vista

## Comportamiento Inaceptable

- Acoso, insultos o ataques personales
- Discriminación o lenguaje ofensivo
- Divulgación de información privada sin permiso
- Conducta hostil, intimidatoria o disruptiva
- Spam o interacciones de mala fe

## Aplicación

Los mantenedores del proyecto podrán moderar, editar o eliminar contribuciones, comentarios o interacciones que no cumplan estas expectativas.

## Reporte

Si observas una conducta inapropiada, repórtala a los mantenedores del proyecto por un canal privado.
